# Python Security Automation Projects

A collection of Python-based cybersecurity utilities developed for
network scanning, host discovery, subdomain enumeration, and PDF protection.

## Projects

### 1. Multithreaded Port Scanner

A Python-based multithreaded TCP port scanner for identifying open ports.

**Technologies:** Python, Socket Programming, ThreadPoolExecutor

[View Repository](https://github.com/Vinaynagari795/multithreaded-port-scanner)

---

### 2. Network Scanner ARP

An ARP-based network scanner for discovering active hosts on a local network.

**Technologies:** Python, Scapy, ARP

[View Repository](https://github.com/Vinaynagari795/network-scanner-arp)

---

### 3. Subdomain Enumerator

A multithreaded Python tool for discovering subdomains using HTTP requests.

**Technologies:** Python, Requests, Multithreading

[View Repository](https://github.com/Vinaynagari795/subdomain-enumerator)

---

### 4. PDF Password Protector

A Python utility for password-protecting PDF files.

**Technologies:** Python, PyPDF2

[View Repository](https://github.com/Vinaynagari795/pdf-password-protector)

---

## Purpose

These projects demonstrate practical Python development,
